# 🚚 TMS — ระบบติดตามรถส่งของ

ระบบจัดการงานขนส่งครบวงจรสำหรับฟลีตขนาดเล็ก ตั้งแต่ **วางแผนจัดรถ → คนขับวิ่งงาน → ศูนย์ควบคุมมอนิเตอร์สด**
สร้างขึ้นเพื่อแทนการคุมรถด้วย LINE กับกระดาษ โดยไม่ต้องจ่ายค่าระบบรายเดือน

ทั้งระบบเป็นไฟล์ HTML ไฟล์เดียวจบต่อหน้าจอ — ไม่มี build step ไม่มี framework เปิดจากเบราว์เซอร์ได้เลย
หลังบ้านใช้ Supabase ซึ่ง free tier รองรับฟลีตขนาดนี้ได้สบาย

## ✨ ฟีเจอร์เด่น

- **ติดตามรถสด** — คนขับส่งพิกัดทุก 15 วินาที ศูนย์เห็นหมุดเคลื่อนแบบลื่นไหล ไม่กระตุก พร้อมทิศทางหัวรถ
- **จัดลำดับเส้นทางอัตโนมัติ** — ออกจากคลัง ส่งหลายจุด ระบบหาลำดับที่ประหยัดเวลา/ระยะทางที่สุดให้ (open-route TSP) แล้วโชว์เทียบกับลำดับที่คีย์มาว่าประหยัดกี่ กม. กี่นาที · เลือกได้ว่าจะใช้ผล auto หรือลากจัดลำดับเอง
- **ยืนยันการส่งรายชิ้น** — คนขับแตะสินค้าทีละรายการ: ส่งครบ / ส่งบางส่วน (กรอกจำนวนจริง) / ตีกลับ ระบบจับพิกัดกับเวลาให้เอง = หลักฐานการส่ง
- **Geofence ล็อกการกดยืนยัน** — อยู่นอกรัศมีจุดส่งกดบันทึกไม่ได้ ต้องขออนุมัติจากศูนย์พร้อมเหตุผล ศูนย์เห็นตำแหน่งคนขับเทียบกับจุดส่งบนแผนที่ก่อนตัดสินใจ
- **KPI ตรงเวลา** — เทียบเวลากดยืนยันจริงกับ ETA ตามแผน สรุปเป็น % ส่งตรงเวลาให้ทันที ไม่ต้องนั่งไล่เอง
- **นำเข้า Excel** — ลากไฟล์แผนจัดรถของเดิมมาวาง จับคู่คอลัมน์ด้วยชื่อหัวตาราง ไม่สนลำดับคอลัมน์
- **ทำงานต่อได้ตอนเน็ตหลุด** — พิกัดเข้าคิวในเครื่องก่อนแล้วค่อยส่ง ไม่มีข้อมูลหาย
- **โหมดมืด / โหมดสว่าง** — ครบทั้ง 3 หน้าจอ จำค่าไว้ในเครื่อง
- **แอปครอบ Android** — ห่อหน้าคนขับเป็นแอปที่ใช้ foreground service เพื่อให้ส่งตำแหน่งต่อได้ตอนพับจอหรือสลับไป Google Maps

## 🛠️ เทคโนโลยีที่ใช้

* **Frontend:** HTML + CSS + JavaScript ล้วน (ไม่มี framework ไม่มี build step) · Leaflet.js (แผนที่) · SheetJS (อ่าน Excel)
* **Backend:** Supabase — PostgreSQL + Realtime (WebSocket) + Row Level Security
* **แผนที่:** OpenStreetMap (ไม่ต้องใช้ API key)
* **เส้นทาง:** OpenRouteService เป็นหลัก → OSRM สำรอง → คำนวณจากเส้นตรงถ้าออฟไลน์
* **มือถือ:** Capacitor 7 + `@capacitor-community/background-geolocation`
* **Deploy:** Netlify Drop หรือ GitHub Pages (เป็น static ทั้งหมด)

## 🚀 วิธีติดตั้งและใช้งาน (Getting Started)

### 1. สร้างฐานข้อมูล
สมัคร [Supabase](https://supabase.com) ฟรี → New project → เลือก region **Singapore**
เข้า SQL Editor แล้วรันไฟล์ตามลำดับ:

```
01_schema.sql           ตารางหลัก + ข้อมูลทดสอบ 5 คัน
02_customers.sql        ทะเบียนลูกค้า
03_geofence_approval.sql  รัศมี geofence + คิวขออนุมัติ
04_route_optimize.sql   จุดรับสินค้า + ที่เก็บผลจัดเส้นทาง
```

### 2. ใส่ค่าเชื่อมต่อ
Project Settings → API → คัดลอก **Project URL** กับ **anon public key**
แล้วแก้ใน HTML **ทั้ง 3 ไฟล์** ให้ใส่ค่าเดียวกัน:

```js
const SUPABASE_URL = 'https://xxxxx.supabase.co';
const SUPABASE_ANON_KEY = 'eyJhbGci...';
```

### 3. เปิดใช้งาน
ลากทั้ง 3 ไฟล์ไปวางที่ [netlify.com/drop](https://app.netlify.com/drop) ได้ลิงก์ทันที ไม่ต้องสมัคร

> ⚠️ หน้าคนขับ **ต้องเปิดผ่าน https** เบราว์เซอร์ถึงจะยอมให้อ่าน GPS — เปิดไฟล์จากในเครื่องตรง ๆ จะใช้ไม่ได้
> ส่วน dashboard กับ planner เปิดจากไฟล์ในเครื่องได้เลย

### 4. ทดสอบ
เปิด `Driver.html` บนมือถือ → เลือกรถ V01 (มีเที่ยวทดสอบรออยู่แล้ว) → กดเริ่มวิ่ง → อนุญาตตำแหน่ง
เปิด `Dashboard.html` บน PC → ต้องเห็นหมุดขึ้นภายใน 15 วินาที = ระบบทำงานครบวงจร

### 5. (ถ้าต้องการ) build แอป Android
ดู [`mobile/README-BUILD.md`](mobile/README-BUILD.md) — รัน 4 คำสั่งแล้วกด Build APK ใน Android Studio

## ⚠️ ข้อจำกัดที่ควรรู้ก่อนใช้จริง

- **RLS เปิดกว้างอยู่** — ช่วงทดสอบใครมี anon key ก็อ่าน/เขียนได้ ก่อนขึ้นใช้งานจริงกับข้อมูลลูกค้าจริงต้องเปลี่ยนเป็น policy ตาม `auth.uid()`
- **จัดเส้นทางคิดทีละคัน** — ยังไม่แบ่งของข้ามคันอัตโนมัติ ยังไม่คิด time window และน้ำหนักบรรทุก
- **เว็บส่ง GPS ตอนพับจอไม่ได้** — เป็นข้อจำกัดของเบราว์เซอร์เอง ต้องใช้แอปครอบใน `mobile/` ถึงจะส่งต่อได้
- **`gps_logs` โตเร็ว** — ส่งทุก 15 วินาทีต่อคัน ควรตั้ง cron ลบข้อมูลเก่าเกิน 90 วัน
- **PDPA** — ต้องแจ้งคนขับเป็นลายลักษณ์อักษรว่าเก็บตำแหน่งช่วงเวลาไหน เก็บนานแค่ไหน ใช้ทำอะไร
